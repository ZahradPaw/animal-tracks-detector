# Приложение для обнаружения и распознвания следов животных России на фото

Программа способна обнаружать следы на изображениях различных природных поверхностях (снег/грязь/песок), и относить их одному из 43 видов животных, обитающих на территории России. 

Приложение доступно в виде веб и мобильного приложения. Модель распознавания загружается локально, поэтому для работы постоянное соединение с Интернетом не требуется. 

## Описание интерфейса

При запуске приложения в интерфейсе доступен блок для загрузки изображения, на котором необходимо распознать следы. После того, как модель будет загружена (смотреть по состоянию индикатора сверху), изображение можно загрузить как из файлов или галереи, так и напрямую из камеры на мобильном устройстве. После выбора изображения можно настроить процент уверенности модели (обнаруженные следы, у которых значения уверенности ниже порога, будут отброшены моделью). После настроек через нажатие кнопки можно запустить процесс распознавания, по итогу которого во втором блоке выведится исходное изображение со всеми обнаруженными следами и их классми, также отдельно отображается список обнаруженныэ видов, отсортированных по уверенности. Полученное изображение можно сохранить в память устройства, нажав кнопку ниже. 

## Описание модели распознавания

Для распознвания следов используется собственная обученная модель на основе YOLO26 Small. Обучение производилось на платформе Google Colab, [ссылка на ноутбук](https://colab.research.google.com/drive/1UybTeuzNXIG1a_0SU2z65jZbgr7fm_5B?usp=sharing). 

Для обучения модели использовался датасет, изображения для которого были отобраны из открытых датасетов, включая такие проекты, как [AnimalClue](https://dahlian00.github.io/AnimalCluePage/) и [OpenAnimalTracks](https://github.com/dahlian00/OpenAnimalTracks), а также другие открытые источники.

## Запуск веб-приложения

Для локального запуска веб-версии приложения необходимо устнаовить Node.js версии 20 и выше. Затем нужно выполнить установку всех зависимостей и запустить приложение в dev-режиме, используя команды:

```
npm ci
npm run dev
```

После успешного запуска интефейс будет доступен на http://localhost:5173/.
